# EST 新上位机 USB 应用协议 V1

## 目的

本协议供全新固件与全新上位机通信。它继续使用现有 USB HID、VID/PID 和帧格式，并保留旧引导所需的固件升级命令；新功能只通过新增命令扩展。

当前协议版本为 `1.0`，首次随固件 `M0.52A` 提供。

## 不变的外层帧

| 字段 | 长度 | 说明 |
| --- | ---: | --- |
| 帧头 | 1 | 固定 `0x68` |
| 方向 | 1 | 电脑到设备 `0x11`，设备到电脑 `0x21` |
| 命令 | 1 | 命令编号 |
| 数据长度 | 2 | 小端 `uint16` |
| 数据 | 可变 | 命令内容 |
| 校验 | 1 | 从帧头到数据末尾逐字节相加，保留低 8 位 |
| 帧尾 | 1 | 固定 `0x16` |

USB 仍使用 `VID=0x0483`、`PID=0x5750` 和 1024 字节 HID report。固件升级仍使用 `0x05`、原来的 1010 字节数据分包和逐包 ACK，没有修改。

## 应用命令

| 命令 | 用途 | 兼容性 |
| ---: | --- | --- |
| `0x01` | 读取六字符固件版本 | 保留 |
| `0x05` | 固件升级及逐包 ACK | 保留，不修改 |
| `0x0D` | 读取六个面板按键 | 保留 |
| `0x17` | 单独控制 A-D 马达并读取测速 | 保留 |
| `0x18` | 单独读取或设置 1-4 号传感器 | 保留 |
| `0x19` | 一次读取整机运行快照 | V1 新增 |

## `0x19` 整机快照

电脑发送空数据帧。设备返回 72 字节数据，所有多字节整数均为小端格式。

| 数据偏移 | 长度 | 内容 |
| ---: | ---: | --- |
| 0 | 1 | 应用协议主版本 |
| 1 | 1 | 应用协议次版本 |
| 2 | 6 | 固件版本，例如 `M0.52A` |
| 8 | 1 | 马达端口数量，当前为 4 |
| 9 | 1 | 输入端口数量，当前为 4 |
| 10 | 1 | 六个面板按键位图 |
| 11 | 1 | 电量档位 `0..4` |
| 12 | 2 | 电池 ADC 原始值 |
| 14 | 2 | 按旧固件比例换算的电池采样点毫伏值 |
| 16 | 4 | 功能位图 |
| 20 | 4 | 本次开机运行时间，毫秒 |
| 24 | 24 | A-D 马达状态，每口 6 字节 |
| 48 | 24 | 1-4 号输入口状态，每口 6 字节 |

每个马达条目：状态 1 字节、有符号功率 1 字节、有符号测速累计值 4 字节。状态 `0/1/2` 分别表示自由滑行、驱动和主动刹车。

每个输入口条目：连接状态、传感器类型、模式、数值有效标志各 1 字节，随后是 2 字节读数。需要 ADC、接收字节数或校验错误等详细诊断时，继续使用 `0x18`。

功能位图：

- bit 0：固件升级；
- bit 1：通用马达控制；
- bit 2：马达测速；
- bit 3：输入传感器；
- bit 4：电池状态；
- bit 5：面板按键。

## 电池说明

电池采样使用 V5 主板确认的 `PF3 / ADC3 channel 9`。电量档位沿用旧 EST APP 的充电电池阈值。返回的 `battery_sample_mv` 是分压采样点数值，不是电池组端子上的实际电压；上位机应优先显示 `battery_level`，在实物校准完成前不要把采样值直接标成电池电压。

## 电脑端验证

在仓库根目录执行：

```powershell
python tools/est_hid_sender/est_hid_sender.py device-status
```

该命令只读取状态，不会启动马达、切换传感器模式或写入固件。
