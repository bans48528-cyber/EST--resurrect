# EST OS 菜单与程序运行开发上下文

日期：2026-08-30

状态：首版菜单、双语和异常状态规则已冻结，尚未开始固件实现

## 1. 文档用途

本文用于把 EST 设备端用户菜单工作迁移到新的开发对话。新任务应先读取本文，再读取：

- `docs/EST_OS_用户菜单与交互设计_V1.md`
- `docs/EST_MicroPython_多槽持久化进度_2026-08-28.md`
- `docs/EST基础硬件验收清单_2026-08-25.md`
- `docs/EST_USB应用协议_V1.md`

原 V1 菜单文档仍作为产品方向参考，但不能直接照搬。当前固件的程序模型、显示能力和运行语义已经发生变化，应以本文的修订结论为准。

## 2. 当前基线和工作区边界

- 已验收固件基线：`M1.13A`
- 基线提交：`fbd3174`
- 协议：`1.22`
- HOLD 能力：`hold-position-control`，bit 21
- M1.14A 正在进行单电机终点收敛优化，当前工作区可能存在未提交修改。

开始菜单开发前必须先执行 `git status`，保留所有现有成果。不得 reset、checkout 或覆盖 M1.14A 修改。菜单实现应等待 M1.14A 完成实机验收并建立干净基线，或者在明确隔离的分支/工作区中开发。

本阶段不修改 EST Studio。

## 3. 已冻结的菜单决策

### 3.1 语言

首版必须同时提供中文和 `English` 两种语言，不能把中文延后；首次启动默认使用中文。

- 所有菜单、弹窗、状态和错误信息使用集中式中英文文本资源，切换语言后立即刷新整个界面。
- 中文界面需要加入覆盖全部系统文字的中文字库，不能只翻译主菜单。
- 只有开发构建确实未包含中文字库时才允许临时回退 `English`，该构建不视为首版验收通过。
- 程序槽位名称允许保存 UTF-8，名称包含当前字库无法显示的字符时回退为 `Slot 0`、`Slot 1` 等稳定名称。

### 3.2 首版功能范围

首版主菜单显示一个最近程序快捷项和已经具备可靠底层能力的入口：

1. 最近下载或最近运行的 `.py` 程序
2. `Programs`
3. `Ports`
4. `Settings`

首版程序功能：

- 列出程序槽位 `0..7`。
- 显示槽位 ID、程序名称和空槽状态。
- 主菜单第一项默认选中最近程序，按确认键直接运行；成功下载或开始运行程序时按发生时间更新该快捷项。
- 主菜单按返回键打开关机确认；弹窗内返回键取消、确认键关机，左右键无操作。
- 运行已保存程序。
- 停止程序。
- 删除程序，删除前必须确认，默认选择取消。

首版端口功能：

- 在同一个 `Ports` 页面直接查看输出口 `A..D` 和输入口 `1..4` 的实时摘要。
- 页面上方显示马达端口和数据，下方显示传感器端口和数据。
- 马达区和传感器区均保留横向四端口选择栏：上下键切换分区，左右键切换当前分区的端口，当前端口反白显示。
- 两个分区分别记住自己的当前端口，并在本页显示选中端口的设备、状态和主数据，不进入下一级详情页。
- 端口页面只读，不从端口页面启动马达。
- 设备拔出后立即显示未连接，不继续显示旧数据。

首版设置功能：

- `Backlight` 范围为 `10%..100%`，使用左右键以 `10%` 步进调节。
- `Volume` 范围为 `0%..100%`，使用左右键以 `10%` 步进调节。
- `Language` 在 `English` 与中文之间切换，并立即更新整个界面。
- `Device Info` 放在设置菜单中，确认进入只读信息页，返回时先回到设置菜单。

首版暂不加入：

- 手动马达驱动。
- 红外遥控。
- 自动休眠设置。
- APP 主动进入 Bootloader 的升级入口。
- 设备端代码编辑。

## 4. 页面效果

交互网页位于：

`docs/est_os_menu_preview.html`

该页面可直接用浏览器打开，通过六个虚拟实体键体验主菜单、主菜单关机确认、程序列表、运行、返回键直接停止、删除确认、端口查看、设置和设备信息。设备下方的“异常状态预览”选择器只用于设计验收，可检查无最近程序、程序异常、Flash/槽位读取失败、端口识别中、低电量和设备拔出，不属于真实设备菜单。

## 5. 按键规则

继续使用原文档冻结的物理映射：

| 按键 | 功能 |
| --- | --- |
| `KEY0` | 返回 |
| `KEY1` | 左 |
| `KEY2` | 上 |
| `KEY3` | 下 |
| `KEY4` | 右 |
| `KEY5` | 确认 |

物理布局：返回键和确认键在上排，四个方向键在下方。交互预览和固件屏幕提示应按这个空间布局表达，不把确认键画在方向键中心。

首版补充规则：

- 普通页面使用上下选择、确认进入、返回退出。
- 主菜单按返回键打开关机确认；弹窗内返回键取消、确认键关机，左右键无操作。
- 程序列表右键打开删除确认。
- 程序运行期间，确认键不被系统菜单占用，按键事件仍提供给用户程序。
- 运行页面不提供暂停或继续功能，不识别 `HOLD OK PAUSE`。
- 返回键直接停止当前用户程序并回到主菜单，不弹停止确认。
- 长按返回键始终调用现有紧急停止路径，停止程序和全部马达并回到主菜单。

需要新增统一的按键事件层，至少提供消抖、按下、松开、短按和长按事件。不得在各页面自行重复实现长按计时。

## 6. 程序运行与停止语义

- 运行状态只有 `RUNNING`，不建立 `PAUSED` 状态，也不保存 VM 或马达任务快照。
- 确认键及方向键不被运行页面消费，继续提供给用户程序读取。
- 返回键由系统保留，按下后立即停止当前用户程序和全部马达，再返回主菜单，不显示确认弹窗。
- 电脑 STOP、程序异常、紧急停止和 USB 主动停止继续使用现有统一安全清理路径。

### 6.1 首版异常状态

| 场景 | 固定行为 |
| --- | --- |
| 无最近程序 | 快捷项显示“暂无最近程序”，确认键无操作；成功运行程序后建立最近项 |
| Flash/槽位读取失败 | 不显示缓存旧列表；显示错误码，确认键重试，返回键回主菜单 |
| 程序运行异常 | 先终止程序和全部马达，再显示错误码；确认键或返回键回程序列表 |
| 端口识别中 | 显示“识别中 / 检测中”，无效数据为 `--`，端口导航保持可用 |
| 设备拔出 | 立即显示“未连接”，状态和值为 `--`，不得保留旧数据 |
| 临界低电量 | 状态栏显示低电量；禁止启动新程序和新马达任务，显示充电提示，返回键回主菜单 |

错误页和状态文字必须同时维护中文与 English，错误码保持语言无关且稳定。

### 6.2 交给固件开发对话决策

- 根据电源电路和现有平台能力确定“关机”的真实语义、安全清理顺序及最终状态；界面只冻结返回取消、确认关机的按键契约。
- 根据现有 Flash/配置服务确定背光、音量、语言和最近程序的持久化格式、写入时机、掉电恢复、损坏回退及磨损控制。
- 根据电池采样和马达安全要求确定临界低电量阈值及恢复滞回。

## 7. 菜单固件结构建议

建议新增独立模块，而不是继续扩展现有默认状态页：

- `est_ui_state`：页面状态机和页面切换。
- `est_ui_renderer`：只负责绘制当前页面。
- `est_key_events`：按键消抖、按下、松开、短按和长按。
- `est_ui_programs`：程序槽位列表、运行、停止和删除适配。
- `est_ui_ports`：输入输出端口只读状态适配。

必须建立唯一屏幕所有权。建议至少区分：

- `EST_SCREEN_MENU`
- `EST_SCREEN_PROGRAM`
- `EST_SCREEN_UPGRADE`
- `EST_SCREEN_MAINTENANCE`

同一时间只能有一个所有者调用 LCD refresh，避免默认状态页覆盖菜单或用户程序画面。

菜单状态机必须非阻塞运行，建议在现有主循环中以 10～20 ms tick 更新。任何页面、弹窗和按键长按判断都不得阻塞 USB、马达控制、传感器和 MicroPython 服务。

菜单应只调用已经冻结的 EST C 服务层，不直接操作 GPIO、马达 PWM、外部 Flash 或 MicroPython 内部数据结构。

## 8. 推荐版本切分

### 第一阶段：菜单内核

- 中英文文本资源和中文字库。
- 屏幕所有权。
- 按键事件层。
- 主菜单。
- `Programs`、`Ports`、`Settings`、`Device Info` 静态和动态页面。

### 第二阶段：程序管理

- 8 槽列表和滚动。
- 运行、返回键直接停止和删除确认。
- 程序异常信息。
- USB 启动程序时菜单自动切换到运行页面。

### 后续阶段

- 手动马达驱动和红外遥控。
- 自动休眠。
- 固件升级入口。

## 9. 首版验收标准

1. 开机完成后进入中文主菜单，不再被旧状态页覆盖；同一版本可立即切换完整 English 界面。
2. 主菜单第一项显示最近下载或最近运行的 `.py` 程序，默认选中且按确认键可直接运行。
3. 主菜单四项的反白区高度缩短且垂直中线一致，文字紧贴图标下方。
4. 主菜单按返回键打开关机确认；弹窗不设置选中项，返回键取消、确认键关机，左右键无操作。
5. 设置菜单可调背光、音量和语言，设备信息从设置进入并返回设置。
6. 中英文切换后所有菜单、弹窗、状态和错误信息立即更新。
7. 上下、确认和返回操作稳定，无重复跳项。
8. 能显示 8 个槽位，空槽和已保存槽位区分清晰。
9. 程序名不可显示时安全回退为槽位名称，不出现乱码或越界。
10. 能运行、返回键停止和删除程序，删除必须二次确认。
11. 运行页面不出现暂停提示或暂停状态，确认键继续提供给用户程序。
12. 停止过程中 USB、传感器、LCD 和系统 tick 保持工作。
13. 长按返回、电脑 STOP、程序异常和紧急停止仍立即执行统一安全清理。
14. 输入或输出设备拔出后页面不显示旧数据。
15. 不破坏 M1.13A/M1.14A 的电机、HOLD、零速、低速、字体、图片、程序槽位和无限运行契约。
16. 无最近程序、程序异常、Flash/槽位读取失败、端口识别中、临界低电量和设备拔出均符合 6.1 的状态与按键规则。
