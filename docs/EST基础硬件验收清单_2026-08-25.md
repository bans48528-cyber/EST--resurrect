# EST 基础硬件验收清单

日期：2026-08-26

这份清单只记录实物已经证明的结果。当前 C 设备实机版本为 `M0.76A`；当前诊断布局为 A 大型、B 空、C 大型、D 中型。M0.72A 已完成静止识别、高低相位、实时拔插归零和单电机持续定速验收；M0.73A 已完成首批 `est_motor` C API 适配回归；M0.74A 已完成多端口独立闭环实机验收；M0.75A 已完成首版双大型马达同步；M0.76A 已按产品要求移除双电机自动超时并完成受阻恢复验收。这些仍是硬件驱动测试固件，不是最终产品固件。旧固件主体将被全新固件替代，原 Bootloader 保留。

## 已通过

| 项目 | 实物结果 |
| --- | --- |
| 旧引导兼容 | 全新 GCC APP 可由旧引导安装、启动，并能继续接收下一版升级 |
| USB 升级 | 原 HID 协议、帧格式和逐包 ACK 保持兼容；正常开机和旧引导模式均完成过升级 |
| 基本运行 | 时钟、看门狗、红蓝指示灯和六个面板按键正常 |
| LCD | 版本、四路传感器值、电池及 A-D 马达类型、转速、累计角度和圈数均可完整显示；M0.64A 的 180 像素紧凑排版已在 C 设备通过 |
| 背光 | 已看到全亮、变暗、熄灭、恢复全亮的完整变化 |
| 电池 | 实物满电时 LCD 显示 `BAT:100%` |
| 外部 Flash | 实物确认为 32 MiB `W25Q256JV`；高地址写入、读回、擦除和模式恢复均通过 |
| A-D 马达口 | 正反转、功率、自由滑行、主动刹车、转动计数、单口及多口独立控制均通过 |
| 马达类型与热插拔 | M0.72A 在 A 空、B 中型、C/D 大型布局下连续稳定识别；大型高低相位均通过。D 口拔出后实时变为空口并清除数据，重新插入后恢复大型且测速计数从 0 开始 |
| 1-4 输入口 | 四个端口已逐口验证能够识别和读取现有传感器 |
| 颜色/灰度 | 反射灰度、环境光和颜色模式可读取；颜色名称精度受传感器自身判断范围限制 |
| 触碰 | 按下、松开、防抖及四端口测试通过 |
| 超声波 | 自动识别、距离显示和距离变化通过 |
| 温度 | 修正输入通路切换后能够自动识别并显示温度 |
| 陀螺仪 | A 设备 1 号口的 MPU6050 模块可识别为类型 `0x20`；角度和角速度模式均正常，负角度可按有符号 16 位值读取 |
| 声音输入 | C 设备已确认 NXT 模拟声音传感器自动识别，声音读数随环境变化正常 |
| 红外 | C 设备已确认距离、信标和遥控三种模式；目标远近、信标方向/距离及遥控按键代码均正常 |
| 大型马达角度闭环 | C 设备 B 口以 30% 执行 `+360°/-360°`，实测 `+369°/-365°`，超调 `9°/5°`；方向、自动完成及停车均确认正常 |
| 中型马达角度闭环 | C 设备 B 口以 30% 执行 `+360°/-360°`，实测 `+363°/-366°`，超调 `3°/6°`；方向、自动完成及停车均确认正常 |
| 中型马达三圈闭环 | C 设备 B 口以 30% 执行 `+3/-3` 圈，实测 `+1088°/-1089°`，超调 `8°/9°`；圈数、方向及停车均确认正常 |
| 大型马达三圈闭环 | C 设备 B 口以 30% 执行 `+3/-3` 圈，实测 `+1084°/-1088°`，超调 `4°/8°`；圈数、方向及停车均确认正常 |
| 大型/中型持续定速 | C 大型和 D 中型的 30% 正反向均跟踪目标并安全停止；大型 60% 正反向平均 `58.8%/-61.9%`。中型受控负载时输出会从约 65% 提高到 100%，卸载后转速和输出均恢复基线 |
| 首批 C API 适配 | M0.73A 的 HID 功率、位置和定速命令经 `est_motor_*` 服务层实机通过：10% 点动正常，D 中型 `+60°` 误差 0，C 大型 30% 定速平均 `27.9%`，最终全部安全停止 |
| 多端口独立闭环 | M0.74A 的 C 大型与 D 中型可并发定速及并发相反角度；单独停止 C 后 D 仍继续闭环，两路位置任务独立完成，最终 A-D 功率全为 0 |
| 双大型马达同步 | M0.75A 的 A/C 双大型反向一圈最大同步误差 `5°`；同向 20% 五圈均到 `1814°`，最大误差 `7°`。短暂受阻后可恢复，持续压住 C 会触发联动超时并使两路安全自由滑行。混合大型/中型允许使用，但不作为同步精度验收基准 |
| 双电机无自动超时 | M0.76A 同向 20% 十圈运行约 20 秒仍到 `3606°/3606°`；对 A 施加外力后松开，A 可重新追赶并以 `2707°/2708°` 完成且无 fault。单电机原有超时不变，双电机永久受阻需用户显式停止 |
| 整机状态命令 | USB 可一次读取版本、电池、按键、四路马达及四路输入口状态 |

## 当前边界

- `M0.44A-M0.72A` 的升级包均保留在 `firmware/releases`，失败、部分通过或待验证的包只用于追溯和指定测试，不能当作正式发布版本。
- 音频问题单独留到后续处理，不阻塞已经通过的马达、传感器、显示和 USB 基础功能整理。
- 当前定速控制能够补偿外力，但没有电流检测或堵转保护；测试和后续 API 必须限制持续堵转时间，并预留统一故障停止语义。
- 下一阶段应在这套驱动基础上定义稳定的设备控制接口和新上位机通信，而不是继续扩展临时开机自测流程。
