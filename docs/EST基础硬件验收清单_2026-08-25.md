# EST 基础硬件验收清单

日期：2026-08-25

这份清单只记录实物已经证明的结果。当前 C 设备实机版本为 `M0.71A`；当前诊断布局为 A 大型、B 中型、C 大型、D 空。M0.69A 固定布局静止识别已通过，但 M0.70A 热插拔空口识别未通过；M0.71A 已刷入并开始数字电平诊断。这些仍是硬件驱动测试固件，不是最终产品固件。旧固件主体将被全新固件替代，原 Bootloader 保留。

## 已通过

| 项目 | 实物结果 |
| --- | --- |
| 旧引导兼容 | 全新 GCC APP 可由旧引导安装、启动，并能继续接收下一版升级 |
| USB 升级 | 原 HID 协议、帧格式和逐包 ACK 保持兼容；正常开机和旧引导模式均完成过升级 |
| 基本运行 | 时钟、看门狗、红蓝指示灯和六个面板按键正常 |
| LCD | 版本、四路传感器值、电池及 A-D 马达类型、转速、累计角度和圈数均可完整显示；M0.64A 的 180 像素紧凑排版已在 C 设备通过 |
| 背光 | 已看到全亮、变暗、熄灭、恢复全亮的完整变化 |
| 电池 | 实物满电时 LCD 显示 `BAT:100%` |
| 外部 Flash | 实物确认为 32 MiB `W25Q256JV`；高地址写入、读回、擦除和模式恢复均通过 |
| A-D 马达口 | 正反转、功率、自由滑行、主动刹车、转动计数、单口及多口独立控制均通过 |
| 1-4 输入口 | 四个端口已逐口验证能够识别和读取现有传感器 |
| 颜色/灰度 | 反射灰度、环境光和颜色模式可读取；颜色名称精度受传感器自身判断范围限制 |
| 触碰 | 按下、松开、防抖及四端口测试通过 |
| 超声波 | 自动识别、距离显示和距离变化通过 |
| 温度 | 修正输入通路切换后能够自动识别并显示温度 |
| 陀螺仪 | A 设备 1 号口的 MPU6050 模块可识别为类型 `0x20`；角度和角速度模式均正常，负角度可按有符号 16 位值读取 |
| 声音输入 | C 设备已确认 NXT 模拟声音传感器自动识别，声音读数随环境变化正常 |
| 红外 | C 设备已确认距离、信标和遥控三种模式；目标远近、信标方向/距离及遥控按键代码均正常 |
| 马达类型 | C 设备运行 M0.69A，在 A/C 空口、B 大型、D 中型布局下连续三轮静止刷新均得到 `none/large/none/medium`，全部报告无识别动作；弱上拉范围分别为 A `275..278 mV`、B `559..561 mV`、C `281 mV`、D `427..429 mV` |
| 大型马达角度闭环 | C 设备 B 口以 30% 执行 `+360°/-360°`，实测 `+369°/-365°`，超调 `9°/5°`；方向、自动完成及停车均确认正常 |
| 中型马达角度闭环 | C 设备 B 口以 30% 执行 `+360°/-360°`，实测 `+363°/-366°`，超调 `3°/6°`；方向、自动完成及停车均确认正常 |
| 中型马达三圈闭环 | C 设备 B 口以 30% 执行 `+3/-3` 圈，实测 `+1088°/-1089°`，超调 `8°/9°`；圈数、方向及停车均确认正常 |
| 大型马达三圈闭环 | C 设备 B 口以 30% 执行 `+3/-3` 圈，实测 `+1084°/-1088°`，超调 `4°/8°`；圈数、方向及停车均确认正常 |
| 整机状态命令 | USB 可一次读取版本、电池、按键、四路马达及四路输入口状态 |

## 未通过或暂缓

| 项目 | 当前结论 |
| --- | --- |
| 音频播放 | 可以出声，WAV 数据通道下音量也有提高，但播放过程仍不正常；没有通过“一次正常播放”验收，暂缓处理 |
| B 异常样机 | 两次完整接收 M0.57A 后仍停在启动动画、蓝灯常亮且无 USB HID；相同固件已在 A、C 正常启动，因此 B 不再作为通用固件开发基线 |

## 暂未测试

| 项目 | 原因 |
| --- | --- |
| 马达实际热插拔流程 | M0.70A 实机未通过：空口会出现与大型马达低相位重叠的约 `249/250/561 mV` 三阶段数据。M0.71A 已升级并确认 D 空口为 `246..249/246..249/559..562 mV`、数字低；A/C 大型高相位数字高，B 中型低相位数字低。尚未捕获大型低相位的数字状态，分类仍未修改，D 空口仍显示大型 |
| 大型/中型持续定速 | `M0.65A` 已实现类型感知的持续闭环定速及自由滑行/主动刹车停止；尚待两类马达正反向实机验收 |
| USB Host、蓝牙等外围 | 本轮尚未进入对应功能测试 |

## 当前边界

- `M0.44A-M0.71A` 的升级包均保留在 `firmware/releases`，失败、部分通过或待验证的包只用于追溯和指定测试，不能当作正式发布版本。
- 音频问题单独留到后续处理，不阻塞已经通过的马达、传感器、显示和 USB 基础功能整理。
- 下一阶段应在这套驱动基础上定义稳定的设备控制接口和新上位机通信，而不是继续扩展临时开机自测流程。
