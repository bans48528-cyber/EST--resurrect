# EST 新电脑开发环境与迁移清单

更新日期：2026-08-21

## 1. 克隆仓库

```powershell
git clone https://github.com/bans48528-cyber/EST--resurrect.git
cd EST--resurrect
```

完整历史资料不在 Git 中。需要查看旧 GUI、图片、原理图全集或完整官方工程时，再通过网盘同步项目文件夹。

## 2. 必需工具

当前已验证环境：

- GNU Arm Toolchain `12.2.1` (`12.2.MPACBTI-Rel1`)，命令名为 `arm-none-eabi-gcc`。
- GNU Make `4.4.1` 或兼容版本。
- Python `3.12`；打包器、验证器、测试和 HID 发送器只使用 Python 标准库。
- Windows 10/11；HID 发送器使用 Windows HID/SetupAPI。

把 `arm-none-eabi-gcc`、`arm-none-eabi-objcopy`、`arm-none-eabi-objdump`、`arm-none-eabi-size`、`make` 和 `python` 加入 `PATH`。

## 3. 首次验证

```powershell
.\scripts\verify_toolchain.ps1
```

脚本默认调用 `make` 和 `python`。命令名不同时可传入 `-MakeCommand`、`-PythonCommand`；例如 `-MakeCommand mingw32-make`。

构建成功必须同时满足：

- 9 项单元测试通过。
- 自动验证器确认 APP 起点 `0x08010000`。
- 初始 MSP 为 `0x2002D3B0`，不得改回边界值 `0x20030000`。
- 包头为 `APP=`，升级包大小为 262144 字节。
- HID VID/PID 为 `0483:5750`，输入/输出报告 caps 为 1025。

工程已经内置固定版本的 libopencm3，commit 为 `2da12dc96e0b9e42a3332348dd9b02a0a17981f8`，不需要首次联网下载依赖。

## 4. 实机工具

以下命令从仓库根目录执行：

```powershell
python tools/est_hid_sender/est_hid_sender.py ping
python tools/est_hid_sender/est_hid_sender.py flash --file firmware/releases/M0.19A/est_minimal_upgrade_app_M0.19A.upgrade.bin
```

禁止发送 `M0.09A`。升级前必须确认设备心跳和目标文件版本；不要把原始 `.bin` 当作升级包发送。

## 5. 权威参数

| 项目 | 值 |
| --- | --- |
| Bootloader 心跳 | `03.00B` |
| APP 起点 | `0x08010000` |
| 升级包存储起点 | `0x08080000` |
| Bootloader 原始 APP 读取起点 | `0x08080004` |
| 包头 | `APP=` |
| 长度低半字 | `0x0800C000` |
| 长度高半字 | `0x0800C008` |
| APP 配置/状态 | `0x0800C010` |
| 后续 APP 初始 MSP | `0x2002D3B0` |

## 6. 当前设备与源码差异

当前设备运行已验证的 `M0.19A`。该版本由 `M0.18A` 接收升级包后安装，按官方 APP 行为在升级提交后拉低 `PE2/PB_CON` 关机，等待用户重新开机；已完成构建、检查、260 包发送、冷启动搬运、屏幕更新 `0-100` 观察和心跳复核。
