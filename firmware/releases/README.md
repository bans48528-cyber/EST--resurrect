| `M0.43A` | 已实机验证 | 新增通用马达命令 `0x17`：A-D 端口选择、`-100%..+100%` 有符号功率、自由滑行、主动刹车、测速读取和计数清零。A/D 独立与同时控制通过；D 口 80% 自由滑行/主动刹车后续计数为 `136/13`；当前设备运行版本 |
