# 已验证固件发布包

| 版本 | 状态 | 用途 |
| --- | --- | --- |
| `M0.16A` | 已实机验证 | 使用官方 MSP 的长入口信标版本，适合启动链路诊断 |
| `M0.17A` | 已实机验证 | 约 2 秒入口签名，之后仅蓝灯慢闪；M0.18A 的升级来源版本 |
| `M0.18A` | 已实机验证 | 约 2 秒入口签名，之后仅蓝灯慢闪；M0.19A 的升级来源版本 |
| `M0.19A` | 已实机验证 | 屏幕显示更新 `0-100`，随后约 2 秒入口签名，之后仅蓝灯慢闪；M0.20A 的升级来源版本 |
| `M0.20A` | 已实机验证 | 使用模块化发送器完成 260 包升级；M0.21A 的升级来源版本 |
| `M0.21A` | 已实机验证 | 使用带 manifest 校验、版本防错和日志的工程化升级工具完成升级 |
| `M0.22A` | 已实机验证 | 电源、LED、时基和看门狗拆分为独立模块 |
| `M0.23A` | 已实机验证 | 六个面板按键及组合按键诊断通过 |
| `M0.25A` | 已实机验证 | 屏幕显示版本号、USB 心跳和按键诊断通过；当前设备运行版本 |

目录内只保存可交给升级工具的 `.upgrade.bin` 和对应 manifest。不要发送 `M0.09A`、存在 LCD/USB 引脚冲突的 `M0.24A`，也不要发送构建目录中的原始 `.bin`。
