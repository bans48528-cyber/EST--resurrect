# EST OS UI Font

The Simplified Chinese menu glyphs in `src/est_ui_font_data.c` are a bitmap
subset generated from `NotoSansCJKsc-Regular.otf` with
`tools/generate_ui_font.py`.

- Upstream: https://github.com/notofonts/noto-cjk
- Font: Noto Sans CJK SC Regular
- Source font SHA-256: `2c76254f6fc379fddfce0a7e84fb5385bb135d3e399294f6eeb6680d0365b74b`
- License: SIL Open Font License 1.1; see `LICENSE`

The full OTF is a build input only and is intentionally not stored in this
repository. The generated bitmap subset remains subject to the OFL.
