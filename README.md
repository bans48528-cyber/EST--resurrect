# EST 3.0 重构与 Bootloader 兼容工程

本仓库保存 EST 3.0 主控重构中可复现、可审计的关键文件。大体量历史 GUI、图片和完整旧工程通过网盘同步，不进入 Git。

## 当前状态

- 当前实机版本：`M1.04A`，仍使用原 `03.00B` Bootloader；USB 心跳、协议 `1.15`、整机快照、电池、四路传感器、屏幕、蓝灯和背光普通回归已通过。它是全新产品固件的阶段性版本，不是最终产品固件。
- 全新 GCC APP 已验证可由旧 Bootloader 安装、启动并继续升级；正常 APP 模式也可直接接收升级包。
- A-D 马达驱动与计数、1-4 输入口、颜色/灰度、触碰、超声波、温度、LCD、六个按键、电池、背光及外部 Flash 已分项通过实机测试。
- 音频播放尚未通过：目前可以出声且音量已提高，但播放过程仍不正常，已暂缓并保留为后续独立问题。
- 升级工具的 manifest 校验、版本防错、逐包 ACK、设备状态读取和升级日志均有自动化测试及实机记录。
- 马达、底盘、传感器、屏幕、按键、双色灯、背光、电池和系统已建立统一 `est_*` C 服务接口；官方 MicroPython `v1.29.0` 已集成并支持 RAM 源码执行。
- M0.97A 已建立主循环与 MicroPython VM 共用的 1 ms C 服务 tick。1 秒 Python 忙循环期间 tick 增加 1001 次，红外 UART 接收计数从 3285 增至 6030，证明 Python 占用 VM 时底层实时服务仍持续运行。
- M0.98A 已开放正式只读 `est.Sensor(1..4)`、`est.buttons` 和 `est.battery` MicroPython API；四路传感器对象、按键掩码、电池状态和非法端口异常均已实机通过。
- M0.99A 已开放 `est.Motor("A".."D")` 的类型、状态、停止方式、功率、目标/实际速度、角度、错误和状态元组，以及逐端口 `COAST/BRAKE` 安全停止。A/C 大型、B 空、D 中型的 959 字节真机脚本 15 ms 返回 4，结束后四路仍为 coast/power 0。
- M1.00A 已开放单马达 `run_power()`、`run_speed()`、`run_angle()` 和 `reset_angle()`。A 口大型马达在强制 GC 循环中稳定闭环并精确完成 `+90°`，D 口中型马达精确完成 `-90°`；正常结束、Python 异常、硬超时和电脑主动停止后 A-D 均为 coast/power 0。
- M1.01A 已开放 C 层计时的 `Motor.run_time()`。A 口大型马达在 13 次强制 GC 下准确完成 1200/1000 ms 正反转，D 口中型马达准确完成 800/800 ms；自动滑行、自动刹车、中途取消和异常清理均通过。
- M1.02A 已开放 `MotorPair` 和 `DriveBase`，完成同型号双电机的持续、定时、角度、直行和转向控制，并通过对象停止、异常清理与电脑主动停止验收。
- M1.04A 已开放七种类型化传感器类、模式切换、模式读取和端口重启。当前连接的红外、声音、陀螺仪、超声波已完成三轮真机脚本；陀螺仪归零采用对象内软件零点。颜色、触摸和温度类已实现并进行类型检查，等待对应实物回归。
