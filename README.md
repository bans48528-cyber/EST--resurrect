# EST 3.0 重构与 Bootloader 兼容工程

本仓库保存 EST 3.0 主控重构中可复现、可审计的关键文件。大体量历史 GUI、图片和完整旧工程通过网盘同步，不进入 Git。

## 当前状态

- 当前实机版本：`M0.91A`，仍使用原 `03.00B` Bootloader；M0.92A 用户界面公共 C API 已构建并等待实机回归。它们都是全新产品固件的阶段性版本，不是最终产品固件。
- 全新 GCC APP 已验证可由旧 Bootloader 安装、启动并继续升级；正常 APP 模式也可直接接收升级包。
- A-D 马达驱动与计数、1-4 输入口、颜色/灰度、触碰、超声波、温度、LCD、六个按键、电池、背光及外部 Flash 已分项通过实机测试。
- 音频播放尚未通过：目前可以出声且音量已提高，但播放过程仍不正常，已暂缓并保留为后续独立问题。
- 升级工具的 manifest 校验、版本防错、逐包 ACK、设备状态读取和升级日志均有自动化测试及实机记录。
- 马达、底盘、传感器、屏幕、按键、双色灯和背光已逐步建立统一 `est_*` C 服务接口，为后续 MicroPython 与全新上位机复用同一硬件能力做准备。

## 关键目录

| 路径 | 内容 |
| --- | --- |
| `firmware/minimal_upgrade_app` | STM32F429 最小 APP 源码、构建脚本、验证器和测试 |
| `firmware/releases` | 各阶段升级包、manifest 及明确的实机验收状态 |
| `firmware/official_est3_app` | 官方 EST 3.0 APP 恢复包 |
| `tools/est_hid_sender` | Windows HID 固件升级工具，支持离线校验、版本防错、分类错误和升级日志 |
| `references/official_est3` | 与升级、跳转、电源和 LCD 相关的官方源码证据 |
| `docs` | 引脚、协议结论、项目范围、调试进度和迁移说明 |
